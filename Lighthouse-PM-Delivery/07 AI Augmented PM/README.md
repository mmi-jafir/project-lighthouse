# AI-Augmented PM Practice
### Knowledge Infrastructure Workstream — Project Lighthouse

This folder documents how AI tools were used to run this project more effectively — a distinct capability from the platform's own AI features (documented in the Transformation Strategy repository) and from the automated PM triggers in `../04 Automation/`.

Each file below includes the prompt used and an example of the resulting output, edited for realism and to reflect this project's actual data.

| File | Use Case |
|---|---|
| `Status Report Prompt.md` | Drafting the narrative sections of the monthly status report from raw tracker data |
| `Stakeholder Email Prompt.md` | Drafting a stakeholder-appropriate communication from a short set of facts |
| `Meeting Notes to Actions.md` | Converting raw meeting notes into structured action items |
| `Risk Drafting Assistant.md` | Turning a brief risk description into a properly structured RAID Log entry |
| `Retrospective Summary Prompt.md` | Synthesizing scattered retrospective input into a coherent summary |

**A note on how this was used:** in every case, AI drafted a first pass; a person reviewed, corrected, and took ownership of the final version before it was sent or logged. This reflects a realistic, responsible use of AI in PM practice — a productivity aid, not a decision-maker.
