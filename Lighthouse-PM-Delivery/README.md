# Lighthouse PM Delivery
### Project Management Lens — Project Lighthouse

*Part of the Project Lighthouse: Global Knowledge Infrastructure Program at Solstice Advisory. See the [Program Overview](../Project-Lighthouse) for the full business case and companion repository.*

---

## Executive Summary

This repository documents the **end-to-end project management delivery** of the Knowledge Infrastructure workstream within Project Lighthouse — a simulated 18-month, €750K initiative to introduce a governed, AI-enabled knowledge platform for consultants at Solstice Advisory, a fictional global consulting firm. It covers the full project lifecycle: charter, planning, execution, controls, communications, and closure — including realistic events (a mid-project cost variance, a scope trade-off, a launch-date decision) that required documented PM judgment, not just template completion.

This repository focuses on **how the project was planned, run, and controlled**. For the broader strategic and organizational context this project sits within, see the companion repository: [Lighthouse Transformation Strategy](../Lighthouse-Transformation-Strategy).

---

## Background

Introducing a global Knowledge Infrastructure platform for Solstice Advisory required more than a good idea — it required disciplined delivery: a clear charter and scope, a stakeholder map spanning practices, industries, and geographies, a realistic schedule and budget, and a way of managing risk and change as the project encountered real-world friction. This repository is built as a chronological project story — planning, execution, uncertainty, decisions, adaptation, delivery — rather than a static set of PM templates.

---

## Skills Demonstrated

- **Scope and charter definition**
- **Stakeholder management** — segmented by audience and by practice/industry/geography
- **Risk and issue management (RAID)** — including professional-services-specific risks (ethical walls, incentive misalignment, data residency)
- **Schedule and WBS planning** — phased, wave-based delivery across global regions
- **Budget and financial control** — including a documented mid-project variance and trade-off decision
- **Decision-making under ambiguity** — a structured decision log showing options, analysis, and rationale
- **Communications management** — tailored by audience (executive, project team, employees)
- **Agile/hybrid delivery fluency** — stage-gated governance combined with Agile delivery sprints
- **Process automation** — automating recurring PM tasks (status alerts, escalation triggers, report generation)
- **AI-augmented PM practice** — using AI tools to draft communications, summarize meetings, and support reporting
