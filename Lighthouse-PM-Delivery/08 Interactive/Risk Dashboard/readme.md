# Interactive Risk Dashboard

This folder contains an **interactive HTML demonstration of a project risk dashboard** created for the Project Lighthouse PM Delivery portfolio.

## View the Interactive Demo

**[Open the Risk Dashboard](https://mmi-jafir.github.io/project-lighthouse/Lighthouse-PM-Delivery/08%20Interactive/Risk%20Dashboard/)**

The dashboard demonstrates how project risks can be summarized and presented visually to support risk monitoring, prioritization, escalation, and stakeholder discussion.

## Portfolio Note

This HTML version is included **for demonstration and portfolio purposes**. It is designed to demonstrate the underlying risk-management logic and dashboard concept rather than suggest that project risk management should be implemented specifically in HTML.

In a real delivery environment, similar risk reporting could be implemented using tools such as **Power BI, Tableau, Excel, Smartsheet, Jira, Microsoft Project, or integrated enterprise project and risk-management platforms**, depending on organizational processes and reporting requirements.

## Project Context

This artifact is part of **Project Lighthouse**, a simulated global knowledge-infrastructure transformation program, and supports the **Project Management Delivery** workstream.
