# Interactive Kanban Board

This folder contains an **interactive HTML demonstration of a project Kanban board** created for the Project Lighthouse PM Delivery portfolio.

## View the Interactive Demo

**[Open the Kanban Board](https://mmi-jafir.github.io/project-lighthouse/Lighthouse-PM-Delivery/08%20Interactive/Kanban%20Board/)**

The board provides a browser-based demonstration of how project work can be organized and communicated visually across workflow stages.

## Portfolio Note

This HTML version is included **for demonstration and portfolio purposes**. It is intended to show the structure, logic, and user experience of a project delivery board rather than prescribe HTML as the production tool.

In a real project environment, a similar Kanban workflow could be implemented using tools such as **Jira, Azure DevOps, Trello, Asana, Monday.com, or other project/work-management platforms**, depending on the organization's technology stack and governance requirements.

## Project Context

This artifact is part of **Project Lighthouse**, a simulated global knowledge-infrastructure transformation program, and supports the **Project Management Delivery** workstream.
