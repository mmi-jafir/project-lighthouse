# Interactive Project Dashboard

This folder contains an **interactive HTML demonstration of a project management dashboard** created for the Project Lighthouse PM Delivery portfolio.

## View the Interactive Demo

**[Open the Project Dashboard](https://mmi-jafir.github.io/project-lighthouse/Lighthouse-PM-Delivery/08%20Interactive/Project%20Dashboard/)**

The dashboard demonstrates how key project information can be presented in a concise, interactive format for monitoring delivery and supporting stakeholder communication.

## Portfolio Note

This HTML version is included **for demonstration and portfolio purposes**. It illustrates the type of dashboard and information architecture that could support project governance and decision-making. HTML is not presented as the only or preferred production solution.

In an organizational setting, a comparable dashboard could be developed using tools such as **Power BI, Tableau, Looker Studio, Smartsheet, Microsoft Project, Jira dashboards, or other reporting and project-management platforms**, depending on data sources, access requirements, and the existing technology environment.

## Project Context

This artifact is part of **Project Lighthouse**, a simulated global knowledge-infrastructure transformation program, and supports the **Project Management Delivery** workstream.
